使用说明

写谱就三步

  1. 点数字：点数字 1–7 写音符，点 0 写休止。每点一个，谱子上马上出现一个音。
  2. 选音区和长短：点「音区」选低音/中音/高音，点「长短」选全音符、四分、八分……选一次会一直用，直到你再改。
  3. 加吹法：点「吹法」选吐、打音、波音、倚音等；点「音符」回到写谱。

改错与修改

写错了点「撤销」；撤销多了可以点「重做」。
改旧音符点谱子上的那个音，改完点「继续写」回到末尾。
补一个音点谱子上的音，点「＋ 插入」，再点数字；新音会插在它后面。点「继续写」回末尾。
翻音符修改时用标题两边的 ◀ ▶ 找上一个 / 下一个。
删一个音点谱子上的那个音，再点「删除」；删错了还能撤销。
更多符号反复记号、连音线、换行、颤音等，在「更多」里。

保存与打印

自动保存每次修改都会自动保存在这台设备，不用点保存。
备份点「存到文件」下载一份文件；换设备时点「打开作品」。
打印 / PDF点「打印」先看预览；在打印窗口的“目标”里选“另存为 PDF”，就是 PDF 文件。

预置与编辑

f / g下一个音符降 / 升一个八度
← / →上一个 / 下一个音符；在末尾按 → 回到继续写
. 或 ,切换附点（持续）
Backspace / Delete删除当前音符
Esc回到末尾继续添加
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做

示例：先按 f（降八度）再按 c（八分）再按 3，就在末尾出现「低音 3 的八分音符」。
键盘输入默认接在末尾；用「＋ 插入」进入插入状态后，会在插入点继续插入。要改旧音符，请用鼠标点选后再点下方按钮。
提示：左Ctrl+W、T、Q、1–9 等为浏览器保留键，可能无法拦截，建议以独立窗口 / PWA 方式使用。
